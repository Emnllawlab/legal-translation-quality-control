# 可选风险锚点

这些文件不属于默认运行路径。普通 Clean 翻译不读取本目录。

只有在识别出相应的法系、领域、历史法律或具体概念风险，并且需要进一步核查时，才读取对应文件。锚点提供核查问题和已知失误模式，不提供脱离语境的固定译法。

文件路由：

- china-contract.md：中国大陆法民商事和合同效果
- china-procedure.md：中国大陆法程序和公法效果
- company-property-ip.md：公司、物权、知识产权、海商和刑事效果
- cross-border.md：跨境和争议解决效果
- common-law.md：普通法易混词和程序冲突
- historical-law.md：历史法和跨法系控制

原始合并文件保留在 risk-anchors-source.md，仅用于维护比对，不作为运行时入口。
