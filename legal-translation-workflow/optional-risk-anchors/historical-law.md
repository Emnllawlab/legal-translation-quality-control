# 可选风险锚点：历史法和跨法系控制

本文件只在对应法系、领域或历史法风险被识别后按需读取。它记录已知失误模式，不是完整术语表，也不是固定答案。未列入本文件不代表风险较低。

## 历史法和跨法系控制

| 触发词 | 需要区分的语境 | 控制问题 |
|---|---|---|
| 旧法/历史案件 | 历史法律的措辞可能不同于现行法 | 相关日期当时有效的文本是什么？ |
| 解除（旧合同法语境） | 历史译法可能不同于现行民法典用语 | 选择动词前是否直接核对历史条文？ |
| 解除合同（1999年《合同法》第93—97条直译） | 中国人大网该历史英文文本使用 `dissolve a contract / dissolution of a contract` 表达“解除合同”。该结论只适用于这组可核验条文，不得推广为所有历史法律的默认译法。 | 直接引用或对照这些条文时，是否保留来源措辞并标明文本身份？处理其他历史法规时，是否重新核对，而不是机械套用 `dissolve/dissolution`？ |
| end / cease / terminate | 一般结束事件不当然等于期限届满 | 源文是否明确出现 expiry、expiration 或 term ending？如无，是否避免擅自增加“届满”这一特定事由？ |
| 参照（裁判说理） | 可能是一般援引、类推适用或参照适用，不是固定译法 | 若法院说明被援引规范与本案情形“相当”，可考虑 `by analogy`；成文法的“参照适用”可考虑 `mutatis mutandis`。先判断法律方法，再选择表达。 |
| 撤销（旧合同法语境） | 历史合同法 doctrine 可能与现行民事法律行为的表述不同 | 对象是合同、民事行为、要约还是决定？ |
| 终止（旧法/合同） | 历史文本对结束、解除和消灭的区分可能不同 | 不要默默把原文现代化。 |
| 英国法/美国法 | 同一标签可能具有不同的机构或程序含义 | 选择固定术语前是否确定具体目标法域？ |
| 普通法法域的地方化差异（香港、新加坡等） | 共同的普通法概念不等于当地法规、法院和起草用法 | 是否已确定具体司法辖区，并核对当地机构、法规、程序和 house style？不要把英国、美国、香港或新加坡的 local wording 自动互换。 |
| civil law | 可能指私法，也可能指大陆法系 | 翻译前是否阅读句子和周边标题？ |
| party | 可能指 litigant、contracting party、政治党派或参与者 | 法律关系和程序角色是什么？ |
| institution | 可能指仲裁机构、公共机构或法律制度 | 应使用具体的组织或理论含义。 |
| authority | 可能指法律渊源、机关、权限或授权 | 它是人、文件，还是法律依据？ |
| register/registration | 可能指登记簿、备案或记录行为 | 登记是创设、证明，还是公示权利？ |
| judgment/ruling/order | 不同法域对文书类别的区分 | 保留原文提供的文书类型。 |
| recognition/enforcement | 法律效力与强制实施的区别 | 两个阶段同时出现时保持区分。 |
| official/authoritative translation | 一种需要证据支持的身份表述 | 没有来源时不要把偏好称为 official。 |
